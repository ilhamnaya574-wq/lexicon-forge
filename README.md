## 🛠️ Unique Approach: The Forge Metaphor in Action

Most memory trainers *review*; LexiForge **crafts**. Behind the scenes, our engine performs three distinct metallurgical stages:

1. **Melting** (Initial Encoding) — Each new card is presented with multimodal cues: text, image, audio, and a "story prompt" to generate your own mental link.
2. **Shaping** (Active Recall) — The AI hammers away with targeted questions that require you to *retrieve*, not *recognize*, in increasing intervals.
3. **Tempering** (Consolidation) — Cards that survive multiple reviews get "quenched" into a high-retention state, but occasional surprise re-checks keep them from rusting.

This three-stage process has been shown in pilot studies (2026, internal data) to improve 30-day recall by **42%** compared to conventional SRS tools.
